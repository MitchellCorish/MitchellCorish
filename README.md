# Hi, I'm Mitch 👋

I build and rebuild the systems that utilities, health administrators, and commerce platforms run on.

Most of my work starts in the same place: something important is fragmented. Product behaviour lives partly in code, partly in database configuration, partly in a deployment script, and partly in the head of whoever has been there longest. My job is to find the real behaviour, make it explicit, and build the testing, deployment, and recovery controls that let a team change it without putting customers at risk.

Currently a **Staff Software Engineer** working on enterprise utility platform modernization.

### What I work on

- **Legacy modernization** — separating real product behaviour from customer-specific configuration, and building the evidence to change it safely
- **Regression architecture** — testing production code paths through narrow seams instead of parallel test-only implementations
- **Platform & delivery** — build-once artifacts, configuration-driven deployment, infrastructure as code, rollback and recovery gates
- **Cross-system diagnosis** — where application code, SQL, identity, and third-party integrations meet and nobody owns the boundary
